# ML in banking App

Deploy: https://altelysium.github.io/ML-in-banking

---

## 🚀 Features

- **Authentication**
  - User login functionality

- **Users Table**
  - Display a list of fetched users
  - Sorting by columns
  - Pagination
  - Search functionality
  - Adjustable display limits
  - Ability to add a new user

- **Transactions**
  - List of transactions
  - View detailed information for each transaction

- **Map Integration**
  - Interactive maps powered by Leaflet

---

## 🛠️ Tech Stack & Dependencies

The project uses the following main technologies and libraries:

- **JavaScript (ES6+)**
- **Vue 3**
- **Vuex** — state management
- **Vue Router** — application routing
- **Vite** — development server and build tool
- **CSS** — styling
- **Leaflet** — interactive maps
- **TanStack (Vue Query / Table)** — data fetching and table utilities
- **Node.js & npm** — package management

## ▶️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- **Node.js** (version 16 or higher recommended)
- **npm** or **yarn**

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repository-name.git
   ```
2. Navigate to the project directory:
   ```bash
   cd your-repository-name
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
   or
   ```bash
   yarn install
   ```
4. Build the project for production:
   ```bash
   npm run build
   ```

### Development server

1. Start the development server with Vite:
   ```bash
   npm run dev
   ```
   or
   ```code
   yarn dev
   ```
   The application will be available at:
   ```code
   http://localhost:5173
   ```
